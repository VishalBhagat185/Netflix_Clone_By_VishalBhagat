# Netflix Clone - Mine First Project
# Project Overview

This project is a Netflix Clone that mimics the UI and functionality of the popular streaming platform. It allows users to browse movies and TV shows, view trailers, and experience a responsive, interactive interface. This is built for learning and portfolio purposes.
